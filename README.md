# even-or-odd
a simple Python program that checks whether a number is even or odd.
About
This project was created to practice basic programming concepts and the use of the modulo operator.

How It Works
The program asks the user to enter a number.

It then uses the modulo operator (%) to check whether the number is divisible by 2.

If the remainder is 0, the number is even.

Otherwise, the number is odd.

Technologies
Python

How to Run
Clone the repository:

git clone https://github.com/YOUR-USERNAME/even-or-odd.git

Enter the project folder:

cd even-or-odd

Run the program:

python main.py

Example
Enter a number: 10

10 is even.

Another example:

Enter a number: 7

7 is odd.
